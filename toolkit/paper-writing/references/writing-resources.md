# Paper-writing support resources

42 selected primary-source resources, checked 2026-10-30. [Search the resource hub](https://optimizer077.github.io/paper-review-lab/resources.html) or use the [structured catalog](writing-resources.json).

Selected original-provider resources with direct relevance to manuscript tasks, actionable guidance and disclosed access/inspection limits. This is not an exhaustive or objective ranking.

Writing guides, manuals, reporting standards and tools are maintained separately from the 10,000-paper historical index; support resources may postdate 2022. Metadata checks, page inspection, completed courses, book reading and tool evaluation are distinct.

Use the [task-by-task support guide](writing-support-guide.md) to choose a bounded next revision. Access labels describe the linked resource at inspection time, not a permanent pricing or availability promise.

## Verification and maintenance

Each JSON record includes an inspected-source URL, verification date, summary, use, limits and inspection level. Publisher/author metadata does not imply that a book was read. An indexed-primary-excerpt flag discloses limited direct retrieval. Tool documentation describes claimed functions, not an independent benchmark.

```sh
python paper-writing/scripts/validate_writing_resources.py paper-writing/references/writing-resources.json
```

The validator checks structure and declared provenance; it does not authenticate source claims. Recheck the exact original source when a version, study design, access condition or submission requirement matters.
